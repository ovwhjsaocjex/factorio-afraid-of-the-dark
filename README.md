## Overview

Afraid of the Dark significantly increases the player character's personal light radius and the light emitted by equipment-grid items in Factorio, making nighttime base building and combat much more practical without requiring the player to exclusively build in fully illuminated areas or wait for daylight.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Afraid of the Dark** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Larger Personal Light** | Player character light radius increased for comfortable night vision |
| **Equipment Grid Lights** | Exoskeleton and personal roboport emit more light in the grid |
| **Configurable Radius** | Adjustable light radius multiplier in mod settings |
| **Night Combat Aid** | Improved visibility for defending biters during nighttime attacks |
